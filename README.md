A modern, high-performance developer portfolio designed to showcase backend architectures, full-stack competencies, and engineering projects. Built using **React** and compiled natively with **Vite** for optimized client-side delivery.

---

## 🚀 Key Features

* **Dynamic Dark Mode:** Single-state theme toggling integrated seamlessly right into the Navbar controls.
* **Looping Typewriter Hero:** Interactive terminal-style headline animation built with custom React streaming hooks.
* **Ambient Glassmorphism UI:** Clean card architectures accented by glowing background layers and interactive hover lift physics.
* **Milestone Timeline:** Chronological data presentation highlighting academic credentials and practical software engineering milestones.
* **Client-First Responsiveness:** Fully responsive interface designed with flexible grid and viewport constraints.

---

## 🛠️ Tech Stack

* **Frontend:** React.js (Functional Architecture & Hooks)
* **Styling:** Modern CSS3, Flexbox & Responsive Grid Layouts
* **Tooling & Build:** Vite (ESBuild HMR)
* **Hosting & CI/CD:** Vercel

## 💻 Setup & Installation

Follow these steps to run the portfolio workspace locally:

```bash
# 1. Clone the repository
git clone [https://github.com/raunakranjann/developer-portfolio.git](https://github.com/raunakranjann/developer-portfolio.git)

# 2. Navigate to the project directory
cd developer-portfolio

# 3. Install project dependencies
npm install

# 4. Spin up the Vite development server
npm run dev
